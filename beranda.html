Komponen Dasar Komputer

Pilih kategori komponen komputer yang ingin dipelajari.

⌨️

Perangkat Input

Perangkat input komputer atau perangkat masukan adalah perangkat yang digunakan untuk memasukkan data dan memberikan perintah kepada komputer untuk diproses lebih lanjut.

⚙️

Perangkat Proses

Perangkat proses merupakan komponen yang berperan dalam pengolahan data, operasi aritmatika, logika, dan pelaksanaan instruksi pada sistem komputer.

💾

Media Penyimpanan

Media penyimpanan berfungsi untuk menyimpan aplikasi, berkas, data, dan berbagai informasi yang digunakan oleh perangkat komputer.

🖥️

Perangkat Output

Perangkat output atau perangkat keluaran digunakan untuk menyajikan hasil pengolahan data komputer agar dapat diterima oleh pengguna.

❄️

Perangkat Pendingin

Perangkat pendingin berfungsi membantu menurunkan suhu komponen komputer agar tidak mengalami panas berlebih atau overheat.

⚡

Perangkat Catu Daya

Perangkat catu daya berfungsi menyediakan dan menyalurkan energi listrik yang dibutuhkan oleh berbagai komponen komputer.
