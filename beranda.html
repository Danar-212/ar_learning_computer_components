Komponen Dasar Komputer

Pilih kategori komponen komputer yang ingin dipelajari.

⌨️

Perangkat Input

Perangkat input komputer (perangkat masukan) adalah perangkat yang digunakan untuk memasukkan beberapa data dan memberikan beberapa perintah pada komputer untuk diproses lebih lanjut.

⚙️

Perangkat Proses

Perangkat proses adalah sebuah perintah yang dikerjakan oleh komputer di mana operasi data, aritmatik dan logika dari kumpulan data berjalan.

💾

Media Penyimpanan

Komponen perangkat media penyimpanan ini berfungsi untuk menyimpan aplikasi, berkas, data, dan lain-lain.

🖥️

Perangkat Output

Perangkat output atau perangkat keluaran merupakan perangkat keras yang digunakan untuk mengomunikasikan dan menyajikan hasil dari pengolahan data oleh sebuah sistem komputer dan diterima oleh pengguna.

❄️

Perangkat Pendingin

Perangkat ini berfungsi untuk menurunkan suhu panas berlebih dari komponen utama seperti CPU dan kartu grafis agar komputer tidak mengalami overheat.

⚡

Perangkat Catu Daya

Perangkat ini berfungsi untuk mengubah arus listrik bolak-balik (AC) dari stopkontak menjadi arus searah (DC) dengan tegangan rendah yang stabil untuk dialirkan ke komponen internal komputer.
